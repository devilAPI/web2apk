web2apk – turn any website into an Android app

web2apk is a free, open-source website to APK converter. Enter a URL, choose an app name, color and icon, and download a signed Android app (APK) that opens the site in a full-screen WebView. No Android Studio, no SDK and no sign-up: the APK is built and signed right in your browser, on your own device.

Features

  • Convert any website or web app (PWA) into an installable APK
  • Custom app name, theme color and launcher icon
  • Optional fullscreen mode without a title bar
  • Custom package name, so you can build several apps
  • Signed with your own key, so new builds install as updates
  • Live preview of the app screen and icon
  • Also available as an app for Android, iOS, Windows, macOS and Linux

How to make an Android app from a website

  1. Enter the app name and the website URL.
  2. Pick a color and an icon, and choose fullscreen if you like.
  3. Press Generate and download or share the APK.
  4. Install it on your Android phone.
